description: Review a GitHub issue as a story (INVEST, testable criteria, FR traceability)
---

Use the `reviewer` agent to review GitHub issue #$issue as a story, not as code. Check INVEST,
mechanically checkable acceptance criteria, an unhappy-path and an ownership scenario, FR-x.y
traceability and MVP scope. The review is read-only: do not edit the issue.
Return the verdict (APPROVE or REQUEST CHANGES) with findings.
